## 🚀 Как внести вклад

### 1. Fork и клонирование

```bash
git clone https://github.com/YOUR_USERNAME/ParcingRatesOfCurrency.git
cd ParcingRatesOfCurrency
```

### 2. Создание ветки

```bash
git checkout -b feature/your-feature-name
```

Используйте префиксы:
- `feature/` — новая функциональность
- `bugfix/` — исправление ошибок
- `docs/` — документация
- `refactor/` — рефакторинг кода

### 3. Внесение изменений

Следуйте стандартам кода ниже.

### 4. Тестирование

```bash
# Проверка синтаксиса
python -m py_compile main.py

# Запуск приложения
python main.py
```

### 5. Коммит

```bash
git add .
git commit -m "feature: описание изменений"
```

### 6. Push и Pull Request

```bash
git push origin feature/your-feature-name
```

Создайте Pull Request на GitHub.

- Следуйте [PEP 8](https://pep8.org/)
- Используйте 4 пробела для отступов
- Максимальная длина строки — 100 символов
- Имена переменных: `snake_case`
- Имена классов: `PascalCase`
- Константы: `UPPER_CASE`

## 📋 Структура коммитов

Используйте [Conventional Commits](https://www.conventionalcommits.org/):

```
<type>(<scope>): <description>

[optional body]
```

### Типы коммитов:

- `feat` — новая функциональность
- `fix` — исправление ошибки
- `docs` — документация
- `style` — форматирование
- `refactor` — рефакторинг
- `test` — тесты
- `chore` — сборка, зависимости

### Примеры:

```bash
feat(gui): добавлена тёмная тема
fix(api): исправлена ошибка парсинга валют
docs(readme): обновлена инструкция по установке
refactor(services): оптимизированы запросы к API
```

## 🔀 Pull Request процесс

### Чеклист перед отправкой:

- [ ] Код следует PEP 8
- [ ] Все импорты в начале файла
- [ ] Добавлены type hints
- [ ] Написаны docstring для функций
- [ ] Код протестирован локально
- [ ] Обновлена документация (если нужно)

### Описание PR:

```markdown
## Описание
Краткое описание изменений.

## Тип изменений
- [ ] Новая функциональность
- [ ] Исправление ошибки
- [ ] Рефакторинг
- [ ] Документация

## Чеклист
- [ ] Код протестирован
- [ ] Документация обновлена
- [ ] Коммиты логически разделены

## Скриншоты (если применимо)
```
