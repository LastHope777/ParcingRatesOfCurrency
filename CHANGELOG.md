# История изменений

## [1.0.0] - 2024-03-12

### ✨ Новое
- Современный GUI интерфейс на CustomTkinter
- Поддержка трёх типов активов: валюты, криптовалюты, акции
- Система избранных активов с сохранением в SQLite
- Настройки темы (тёмная/светлая/системная)
- Автообновление данных в реальном времени
- Карточки активов с визуализацией изменений (%)

### 🔧 Изменения
- Полная переработка архитектуры проекта
- Модульная структура кода
- Выделение сервисного слоя для работы с API
- Переход от консольного интерфейса к графическому

### 📦 Зависимости
- customtkinter >= 5.2.0
- requests >= 2.31.0
- beautifulsoup4 >= 4.12.0
- yfinance >= 0.2.31
- Pillow >= 10.0.0

### 🐛 Исправления
- Улучшена обработка ошибок API
- Оптимизирована работа с базой данных
- Устранены проблемы с кодировкой на Windows

---

## [0.1.0] - Предыдущая версия

### Основное
- Консольное приложение для парсинга курсов валют ЦБ РФ
- Базовая визуализация через matplotlib
- Простой вывод данных в консоль
