# 🎉 Asset Tracker v1.0.0 — Первый стабильный релиз!

## 📦 О релизе

**Asset Tracker** — это современное десктопное приложение для отслеживания финансовых активов с красивым и удобным интерфейсом.

### 🌟 Ключевые возможности

- **💱 Валюты** — Курсы валют Центрального Банка РФ
- **₿ Криптовалюты** — Данные о криптовалютах через CoinGecko API
- **📈 Акции** — Котировки акций через Yahoo Finance
- **⭐ Избранное** — Сохранение любимых активов в один клик
- **🎨 Темы** — Тёмная, светлая или системная тема оформления
- **🔄 Автообновление** — Данные обновляются в реальном времени

## 🚀 Быстрый старт

### Установка за 1 минуту

```bash
# Клонирование репозитория
git clone https://github.com/LastHope777/ParcingRatesOfCurrency.git
cd ParcingRatesOfCurrency

# Создание виртуального окружения
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # macOS/Linux

# Установка зависимостей
pip install -r requirements.txt

# Запуск
python main.py
```
