# Шаблоны GitHub

## Шаблон для Issue (баг-репорт)

```markdown
### Описание проблемы
Краткое описание проблемы.

### Шаги воспроизведения
1. Открыть приложение
2. Нажать на...
3. Произошло...

### Ожидаемое поведение
Что должно было произойти.

### Скриншоты
Приложите скриншоты если возможно.

### Информация о системе
- OS: [Windows/macOS/Linux]
- Python: [3.9/3.10/3.11]
- Версия приложения: [1.0.0]

### Логи
```
Вставьте логи ошибки здесь
```
```

## Шаблон для Issue (предложение функции)

```markdown
### Описание предложения
Краткое описание новой функции.

### Проблема
Какую проблему решает эта функция?

### Предлагаемое решение
Как должна работать функция.

### Альтернативы
Рассматривали ли вы другие решения?

### Дополнительный контекст
Любая дополнительная информация.
```

---

## Шаблон для Pull Request

```markdown
## Описание
Краткое описание изменений.

## Тип изменений
- [ ] 🚀 Новая функциональность
- [ ] 🐛 Исправление ошибки
- [ ] 📝 Документация
- [ ] ♻️ Рефакторинг
- [ ] ⚡ Оптимизация

## Чеклист
- [ ] Код протестирован локально
- [ ] Документация обновлена
- [ ] Коммиты следуют Conventional Commits
- [ ] Нет конфликтов слияния

## Скриншоты (если применимо)
Приложите скриншоты изменений UI.

## Связанные Issue
Fixes #123
```
